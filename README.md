# Киночеклист — Топ-500 Кинопоиска

Локальное веб-приложение: личный чеклист просмотренных фильмов из топ-500 Кинопоиска.

Откройте `index.html` в браузере — сервер не нужен.

Список скопирован с Кинопоиска **9 сентября 2026**.

## Возможности

- 500 фильмов: русское и оригинальное название, год, рейтинг КП
- отметка «смотрел» сохраняется в браузере
- поиск по названию и году
- фильтры: просмотр, жанры, года, длительность, сортировка
- случайный фильм из непросмотренных
- карточка фильма: постер, короткое описание и блок «О фильме» с Кинопоиска
- перенос чеклиста в другой браузер через токен — без регистрации

## Как пользоваться

1. Откройте файл `index.html`.
2. Нажмите на фильм, чтобы раскрыть постер и описание.
3. Галочка справа отмечает просмотренное.
4. Кнопка **Фильтры** открывает панель:
   - все / не смотрел / смотрел
   - жанры — можно несколько, фильм должен содержать **все** выбранные
   - сортировка
   - диапазон годов
   - диапазон длительности
5. **Случайный фильм** выбирает один непросмотренный с учётом фильтров.
6. **Сбросить все отметки** — внизу страницы. Сами фильтры сбрасываются отдельно внутри панели.

## Токен чеклиста

Регистрации нет. Отметки можно перенести текстом.

1. Внизу страницы нажмите **Копировать**.
2. В другом браузере откройте то же приложение.
3. Вставьте токен и нажмите **Применить**.

Форматы:

| Токен | Что это |
| --- | --- |
| `K2-0` | пустой список |
| `K2-2653-3C23` | новый короткий токен |
| `KB-…` | новый токен для очень большого числа отметок |
| `kc1.…` | старый токен, его тоже можно применить |

Токен хранит только номера отмеченных фильмов, не имя и не почту.

## Где хранятся данные

Отметки пишутся в `localStorage` этого браузера. Если очистить данные сайта, галочки пропадут — их можно вернуть токеном, если вы его сохранили.

## Источник данных

Названия, рейтинг и ссылки — из выгрузки топ-500 Кинопоиска.

В карточке:

- короткое описание с карточки Кинопоиска
- год, страна, жанр, слоган, режиссёр, длительность, возраст

Постеры подгружаются с CDN Кинопоиска.
